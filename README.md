# ⚡ Impact.AI

AI-powered Software Change Impact Analyzer and Risk Assessment Platform.

## 🎯 Problem Statement
When a software component is modified, it is difficult to identify which dependent components may be affected. This can lead to unexpected errors, increased testing effort, and project delays.

## 💡 Solution
Impact.AI analyzes software component dependencies and assesses the potential impact and risk of a proposed change.

## 🚀 Features
- 📊 Impact Dashboard
- 🧩 Component Management
- 🔗 Dependency Analysis
- ⚠️ Risk Assessment
- 🤖 AI-based Impact Prediction
- 📄 Report Generation

## 🛠️ Technologies
- Python
- Streamlit
- NetworkX
- Scikit-learn
- CSV
